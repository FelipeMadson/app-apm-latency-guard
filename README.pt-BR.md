# Application Performance Monitoring (APM) Latency Guard

Monitor de desempenho de aplicações (APM) para análise de latência em tempo real, detecção estatística de anomalias e cálculo exato de percentis p50/p90/p95/p99 utilizando buffer circular em memória.
